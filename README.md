# TI-BASIC Programs for the TI-84 Plus CE

Small, useful TI-BASIC programs you can type into your TI-84 Plus CE.

## Programs
- **QUAD** — quadratic formula solver (shows both roots)
- **DIST** — distance between two points
- **MIDPT** — midpoint of two points
